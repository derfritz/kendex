- Quoted titles, commit messages, and heredoc data no longer trigger worktree warnings. The hook gives an early advisory for plain kendex commands after the installed CLI on its PATH confirms its project-write protection. Other executable paths must name that same file; the hook refuses them without execution and names the trusted command route. Older executables must be updated before the hook permits these writes. The CLI checks the actual destinations of commands covered by its worktree guard before any write.
